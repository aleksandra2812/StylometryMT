# Corpus of literary machine translation

The big table below depicts the structure of the corpus - it is composed out of novels and collections of short stories that have been translated into English, Polish, French, and Lithuanian. Source languages of the original texts do not contain the four aforementioned languages. In the table one can find information about the original texts (**name of the author**, **original title**, **year of publication** and **source language**) as well as the human-translated works (**title in the target language**, **name of the translator**, **year of publication**). To perform the machine translation, **Google Translate**, **DeepL** and **EU translator** have been used - the system used in translation is also marked in the table.

The smaller table depicts the number of texts that have been translated from each of languages that are not Polish, French, English and Lithuanian. The table also contains information about the word order of each of the languages.
